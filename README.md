# ComposeUiShowcase

> 🚧 **Under Construction**  
> This repository is a work in progress. Features, UI examples, and documentation are actively being added.

## What is this?

**ComposeUiShowcase** is a Kotlin Android UI showcase built using Jetpack Compose.  
It’s meant to serve as a living gallery of UI patterns, components, and animations — a place to explore, experiment, and learn.

## Features (Planned / In Progress)

- Common UI components (buttons, inputs, cards, lists)  
- Custom layouts & responsive UI  
- Animations & transitions  
- Theming (light / dark)  
- Sample screens & use cases  
- Code samples & documentation
